### Описание проекта

**Задача:** имеется датасет клиентов интернет провайдера, нужно создать отчёт в PowerBI об оттоке клиентов (`churn rate`), включая прогноз оттока с применением машинного обучения.

Идея для проекта взята из данного гайда (в описании видео есть ссылки на датасет и примеры SQL скриптов): [YouTube](https://www.youtube.com/watch?v=QFDslca5AX8)

**План:**
1. Выгрузить датасет в PostgreSQL
2. Провести очистку и подготовку данных в виде представлений (views) для передачи в PowerBI
3. Создать ML модель для прогнозирования оттока клиентов
4. Создать отчёт в PowerBI

### Запуск (Windows)

Для запуска требуется:
- **Docker** (с применением docker-comopose) - для запуска контейнера с PostgreSQL
- **Python** - для запуска скриптов переноса данных из CSV файла в Postgres, а также обучения модели прогнозирования оттока
- **DBeaver или pgAdmin** - для проверки БД и импортированных данных
- **PowerBI** - для просмотра отчёта


Краткая инструкция по запуску:
1. Скопировать содержимое данного проекта на ПК
2. Запустить через терминал файл `docker-compose` из папки `postgres_churn_db_container`
3. Создать виртуальное окружение или загрузить напрямую в ваш локальный Python библиотеки из файла `requirements.txt`
4. После запуска контейнера запустить скрипт `import_from_csv_to_postgres.py` из папки `resources/scripts` (если создали виртуальное окружение, не забудьте его активировать)
5. Запустить скрипт очистки данных и создания представлений `refine_data_and_create_views_in_postgres.py`
6. Запустить PowerBI и открыть файл отчёта `telecom_churn_analysis.pbix` (подключите источник заново, если возникнет ошибка подключения, а также убедитесь, что контейнер с БД запущен)

Подробное пошаговое описание процесса создания проекта (согласно плану в начале документа) можете посмотреть в файле: `2_Подробное_описание_процесса.md`

Скриншот готового отчёта:

![Готовый отчёт - основная страница](./img/20_powerbi_summary_page.png)

Какие выводы мы можем сделать при взгляде на данный отчёт:
1. Женщины уходят чаще мужчин
2. Чаще уходят пользователи со сроком пользования до года, либо с большим сроком пользования от 18 мес, а также клиенты с краткосрочными договорами (на один месяц)
3. Самая частая причина отказа от услуг - "Конкуренты"

Проанализировав вышесказанное, можно дать следующие рекомендации:
1. Скорректировать рекламные кампании, ориентированные на женскую аудиторию
2. Предлагать новым клиентам более выгодные условия при заключении долгосрочных договоров, а для старых клиентов - разработать программу лояльности
3. Уделить отдельное внимание изучению конкурентов (цены, условия, оборудование), чтобы повысить собственную конкурентоспособность

Имея подобные данные, можно начать точечно работать с клиентами, приносящими больше всего выручки или с наибольшей платой в месяц. Можно начать с опросов о качестве обслуживания по телефону или электронной почте, чтобы в дальнейшем разработать персонализированные предложения для потенциально уходящих клиентов. Таким образом можно добиться снижения оттока.
